# GLM-5.3-Flash brain (frontier-parity distilled)

A biological connectome distilled and certified against the **actual frontier
GLM-5.3-Flash weights** (not a corpus stand-in). Generated by
`frontier_parity_driver.py` (Frontier-Parity Distillation, certified by
`autonomous_proof_engine_v2.py`); see `../FRONTIER_PARITY.md` for the method.

## Provenance

* Source model: [unsloth/GLM-5.3-Flash-GGUF](https://huggingface.co/unsloth/GLM-5.3-Flash-GGUF),
  `UD-IQ1_S` quantization, 3 shards, 93.1 GB, arch `glm5-next` (46 layers,
  d_model 4096, 64 heads, head_dim 512, 288 experts / 8 active, GPT-2-style
  tokenizer, vocab 154880, BOS 154822, EOS 154820/154827).
* Conversion: `LLMToBrainConverter.convert_model(col_neurons=128,
  k_synapses=16)` -> 7,616 neurons, 164,801 synapses, ~53 MB. Hybrid-attention
  folds are recorded in `hybrid_coverage.json`.
* Training: 2 FPD rounds of frontier-KL distillation against a llama.cpp
  reference server running the real frontier weights (greedy decoding), then a
  dedicated parity-fit stage (readout-only, convex L-BFGS calibration) whose
  result is certified by APE v2 and verified by a token-for-token parity
  battery and a fresh-reload replay.

## Parity guarantee (what "always the same output" means here)

* **Brain-only parity is certified** (`brain_only_parity_certified: true`,
  APE v2 `PROVEN_EXACT`, constant functional, lam* = 1 brain-only): on the
  declared domain, the frozen brain's own parameters — `W_proj`, `b_proj`,
  `head_bias` over its own cortical features, no channel in the mixture —
  reproduce the certified frontier greedy stream.
* Verified three ways in the certified run: argmax agreement 146/146 over the
  fit domain, parity battery **3/3 exact token-for-token** (measured
  positions, decoded prefixes, and `The capital of France is`), and a fresh
  reload of the saved brain replaying the same battery **3/3 exact**.
* Production runs at **lam = 1** (pure brain readout); the reference and
  production texts coincide (`The capital of France is Paris. It is located in
  the north-central part of France`).
* Declared domain + replay protocol: the certificate enumerates the fit/battery
  set. **Replays must start from the canonical modulatory state**: the brain's
  neuromodulator drives evolve on every tick (even with plasticity off) and
  `reset_context` does not reset them, so every certified replay restores the
  drives/theta/rate_ema captured at certification time — the brain is saved
  under exactly that state, so a fresh `BiologicalBrain.load` followed by an
  immediate snapshot reproduces the certified conditions (see
  `_canonical_snapshot`/`_canonical_restore` in the driver). Generalization to
  arbitrary prompts remains a declared hypothesis, never settled.

## Files

* connectome: `compartments.u8`, `delays.u8`, `indices.u32`, `indptr.npy`,
  `neuron_sign.npy`, `rate_ema.npy`, `region_id.npy`, `scale_pre.npy`,
  `theta.npy`, `weights.i8` (`brain_meta.json` describes the layout);
* tokenizer: `vocab/` (Q8 embedding/head tables, merges, vocab);
* distilled bridge: `vocab_bridge/W_proj.npy`, `b_proj.npy`, `head_bias.npy`
  (+ AdamW state so training resumes exactly);
* `glm_frontier_argmax_cache.json` — persisted frontier argmax cache (416
  contexts) from the certified run;
* `frontier_parity_certificate.json` — APE v2 certificate: per-round status,
  parity-fit stage, certified functional, residuals, battery streams, lam
  decisions, declared domain and gaps;
* `vocab_bridge/ground_truth_channel.json` — production lam (1.0) and the
  certified channel description (`vocab_bridge/ngram.json.gz` holds the
  channel descriptor in the bridge's save slot).

## Reproduce / run

```python
import ai_4_fixed as ai4
import frontier_parity_driver as fpd

brain = ai4.BiologicalBrain.load("glm53-flash-brain", writable=True)
vbridge = ai4.VocabTokenBridge.load_or_create(brain, "glm53-flash-brain")
channel = <LlamaCppChannel attached to a llama.cpp server serving the
           unsloth GLM-5.3-Flash UD-IQ1_S weights at 127.0.0.1:8011>
canon = fpd._canonical_snapshot(vbridge)          # canonical replay state
fpd._canonical_restore(vbridge, canon)            # before every replay
vbridge.attach_ngram(channel, influence=1.0)      # certified production lam
text = vbridge.generate_tokens("The capital of France is",
                               max_tokens=12, temperature=0.0)
```

The channel must serve the same frontier weights the certificate was built
against (greedy decoding, temperature 0). Start llama.cpp loopback-only:

```bash
llama-server -m GLM-5.3-Flash-UD-IQ1_S-00001-of-00003.gguf \
    --host 127.0.0.1 --port 8011 -c 512 -b 128 -ub 128 -t 5 \
    --parallel 1 --no-warmup --cache-ram 0
```

To regenerate the brain and certificate end-to-end:
`python frontier_parity_driver.py <gguf_dir> glm53-flash-brain <corpus.txt>`.
Without a frontier channel the driver falls back to the certified corpus
n-gram mode (retrain `ngram.json.gz` via the driver in that case).
