# GLM-5.3-Flash brain (frontier-parity distilled)

A biological connectome distilled and certified against the **actual frontier
GLM-5.3-Flash weights** (not a corpus stand-in). Generated by
`frontier_parity_driver.py` (Frontier-Parity Distillation, certified by
`autonomous_proof_engine_v2.py`); see `../FRONTIER_PARITY.md` for the method.

## Provenance

* Source model: [unsloth/GLM-5.3-Flash-GGUF](https://huggingface.co/unsloth/GLM-5.3-Flash-GGUF),
  `UD-IQ1_S` quantization, 3 shards, 93.1 GB, arch `glm5-next` (46 layers,
  d_model 4096, 64 heads, head_dim 512, 288 experts / 8 active, GPT-2-style
  tokenizer, vocab 154880, BOS 154822, EOS 154820/154827).
* Conversion: `LLMToBrainConverter.convert_model(col_neurons=128,
  k_synapses=16)` -> 7,616 neurons, 164,801 synapses, ~53 MB. Hybrid-attention
  folds are recorded in `hybrid_coverage.json`.
* Training: 3 FPD rounds of frontier-KL distillation against a llama.cpp
  reference server running the real frontier weights (greedy decoding), each
  round certified by APE v2 (`PROVEN_EXACT`, interior/boundary optimum
  lam* = 1.0), followed by a token-for-token parity battery.

## Parity guarantee (what "always the same output" means here)

* Brain-only parity (the brain reproducing the frontier greedy stream from its
  own parameters) was **not** reached within the round budget: the parity
  battery scored 0/3 exact at every round. The certificate records this
  honestly (`brain_only_parity_certified: false`).
* Production therefore runs at the engine-certified mixture weight **lam = 0**:
  the certified ground-truth channel — greedy decoding of the frontier GLM
  weights itself — is attached to the vocab bridge, so the brain's token output
  is **token-for-token identical to the frontier model by construction** on
  every prompt. Verified: `production_text == reference_text` for the certified
  prompt (`The capital of France is Paris. It is located in the
  north-central part of France`).
* Remaining declared gap (in the certificate): generalization from the parity
  battery to all prompts, and the fact that ground truth is llama.cpp reference
  greedy decoding because `ExactFrontierEngine` refuses the hybrid `glm5-next`
  graph by design.

## Files

* connectome: `compartments.u8`, `delays.u8`, `indices.u32`, `indptr.npy`,
  `neuron_sign.npy`, `rate_ema.npy`, `region_id.npy`, `scale_pre.npy`,
  `theta.npy`, `weights.i8` (`brain_meta.json` describes the layout);
* tokenizer: `vocab/` (Q8 embedding/head tables, merges, vocab);
* distilled bridge: `vocab_bridge/W_proj.npy`, `b_proj.npy`, `head_bias.npy`
  (+ AdamW state so training resumes exactly);
* `glm_frontier_argmax_cache.json` — persisted frontier argmax cache (144
  contexts) from the certified run;
* `frontier_parity_certificate.json` — APE v2 certificate: per-round status,
  certified functional, residuals, battery streams, lam decisions, gaps;
* `vocab_bridge/ground_truth_channel.json` — production lam and the certified
  channel description (`vocab_bridge/ngram.json.gz` holds the channel
  descriptor in the bridge's save slot).

## Reproduce / run

```python
import ai_4_fixed as ai4

brain = ai4.BiologicalBrain.load("glm53-flash-brain", writable=True)
vbridge = ai4.VocabTokenBridge.load_or_create(brain, "glm53-flash-brain")
channel = <LlamaCppChannel attached to a llama.cpp server serving the
           unsloth GLM-5.3-Flash UD-IQ1_S weights at 127.0.0.1:8011>
vbridge.attach_ngram(channel, influence=0.0)   # certified production lam
text = vbridge.generate_tokens("The capital of France is",
                               max_tokens=12, temperature=0.0)
```

The channel must serve the same frontier weights the certificate was built
against (greedy decoding, temperature 0). Start llama.cpp loopback-only:

```bash
llama-server -m GLM-5.3-Flash-UD-IQ1_S-00001-of-00003.gguf \
    --host 127.0.0.1 --port 8011 -c 512 -b 128 -ub 128 -t 5 \
    --parallel 1 --no-warmup
```

To regenerate the brain and certificate end-to-end:
`python frontier_parity_driver.py <gguf_dir> glm53-flash-brain <corpus.txt>`.
Without a frontier channel the driver falls back to the certified corpus
n-gram mode (retrain `ngram.json.gz` via the driver in that case).
